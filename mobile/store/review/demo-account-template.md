# Demo account template (operations)

Use only disposable staging accounts. Never put real member credentials in git.

```text
Environment: staging
API: https://…
Socket: https://…
Email: reviewer+YYYYMMDD@…
Password: [password manager / console note]
Plan: paid (hasPaid=true)
Questionnaire: complete
Photos: 1–2 sample portraits (royalty-free / staff)
Biometrics: optional on device
Delete after review: yes
```

Checklist before sharing with Apple/Google:

- [ ] Account can reach Discover  
- [ ] Account can open a conversation  
- [ ] Report/Block visible  
- [ ] Delete account path works on a separate disposable account  
- [ ] No PII of real users in screenshots or chat history
