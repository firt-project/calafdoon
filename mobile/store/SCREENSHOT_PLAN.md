# Screenshot capture guide

Placeholders in `store/*/screenshots/{en,so}/` must be replaced with **real** device captures before store submission.

## Rules

- Use staging / disposable accounts only
- Scrub emails, phones, real names of non-consenting people
- No localhost, debug banners, or DevTools
- No fabricated match counts or fake chat
- Capture both light and dark if listing supports it (optional)
- EN and SO when marketing both languages

## Order (Play / App Store)

1. Welcome / brand  
2. Discover card  
3. Match success  
4. Messages list  
5. Chat thread  
6. Profile  
7. Photo editor  
8. Settings / safety  

## Sizes

- Android: phone (e.g. 1080×1920); tablet optional if supported  
- iOS: 6.7" and 6.1" required sets per current Apple guidance  

Update `SCREENSHOT_PLAN.md` when captures are complete.
